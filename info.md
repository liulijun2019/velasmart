# VelaSmart

[![GitHub Release](https://img.shields.io/github/v/release/liulijun2019/velasmart?style=flat-square)](https://github.com/liulijun2019/velasmart/releases)
[![HACS](https://img.shields.io/badge/HACS-Custom-orange.svg?style=flat-square)](https://hacs.xyz)

Home Assistant integration for **VelaSmart** smart curtains.

- Open / close / set position (0–100%)
- Automatic cloud polling every 30 seconds
- Multiple accounts supported
